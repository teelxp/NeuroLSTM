# Переход с прежнего Neuro.py

Вместо единственного скрипта используется пакет `neurolstm`. Корневой `Neuro.py` остается точкой входа командной строки и экспортирует основные классы, но это не обещание совместимости всех прежних вызовов Python API.

Конструктор новой модели:

```python
from neurolstm.config import load_config
from neurolstm.model import AdaptiveLSTM

cfg = load_config("configs/gas_local.json")
model = AdaptiveLSTM(cfg["model"], cfg["data"]["horizons"], cfg["semantics"])
```

Метод `forward` получает `(x, mask, mass_rate)`, где x и mask имеют форму `[B,T,3,3]`, mass_rate — `[B,T,1]`. Результат — словарь нормированных прогнозов, логита/вероятности при включенной классификации и скрытого состояния. Обратный переход давления и расхода в физические единицы выполняется сохраненным нормировщиком, а не новым fit на пользовательском окне.

Прежние вызовы с `(x,z,m_in)` и ожиданием пары `(outputs, states)` нужно адаптировать в вызывающем коде. Готовая команда `predict` реализует чтение телеметрии, применение сохраненных шкал, вызов модели и запись результата. Загрузка старого `best_adaptive_lstm.pth` не переносит веса автоматически в новую модель.

Изменения, которые нельзя выполнять механически:

- Не переименовывать `mass_in` в `mass_out`. Для двух колонок нужны реальные независимые измерения.
- Не объявлять старый `target_pressure` будущим значением без проверки его временного смысла. Новый конвейер формирует цели по явно заданным горизонтам из исходного ряда pressure.
- Не сохранять прежние значения Accuracy, F1 и времени под новой версией. Новые файлы результатов создаются фактическими расчетами.
- Не использовать будущие расходы/T/Z как эксплуатационные входы. Они допустимы как ретроспективные основания физической функции потерь.

Django-приложения, формы БД и карты не входят в данный репозиторий. Их интеграционный код должен использовать новый контракт нейросетевого модуля. Изменение этого программного контракта не требует само по себе переписывания математической методики диссертации, но описание конкретной конфигурации и экспериментальной версии должно ей соответствовать.
